# Tu Chofer Premium — Demo UX/CRO Analysis

Versión demo de landing page para servicio de chofer privado premium.

## Características Demo

- **Modo oscuro/claro** con persistencia en localStorage
- **Splash screen** animado con logo de la app
- **Scroll reveal** con IntersectionObserver
- **Efecto ripple** en botones
- **Micro-interacciones** en hover de cards e iconos
- **Badge DEMO** visible en la parte superior

## Estructura

1. Hero (perfil, rating, stats desplegables, CTAs)
2. Viajes Recurrentes
3. Zona de Trabajo y Horarios
4. Experiencia & Vehículo
5. Testimonial
6. Modalidades de Servicio
7. Footer con CTA final

## UX Notas

- Botones con altura mínima de 52px para fácil uso táctil
- Animaciones suaves con cubic-bezier personalizado
- Placeholders visuales con CSS (sin imágenes reales)
- Diseño mobile-first, responsivo hasta 640px+
