# Tu Chofer Premium — Demo App

Versión demo de landing page mobile-first para servicio de chofer privado premium.

## Descripción

App demo tipo Uber/Material Design con modo oscuro, diseñada para mostrar el concepto de:
- Landing page de chofer privado
- CTA vía WhatsApp con mensajes predefinidos
- Guardado de contacto VCF
- Tema claro/oscuro adaptable

## Stack

- HTML5 + CSS3 + JavaScript (vanilla)
- Sin dependencias externas
- Google Fonts: Inter
- Iconos SVG inline

## Demo

Para usar: abre `index.html` en cualquier navegador.
