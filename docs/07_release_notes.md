# 07 — Release Notes

> **Proyecto:** Tu Chofer Premium
> **Versión:** 1.0.0
> **Release:** 2026-06-24

## Resumen

Landing page mobile-first demo para servicio de chofer privado premium. Conecta conductores con clientes a través de WhatsApp con mensajes predefinidos y experiencia visual premium.

## Novedades en esta versión

### Features
- Splash screen animado con logo de la app
- Perfil de chofer con calificación 5.0 y estadísticas animadas (2,500+ viajes, 3+ años, 98% puntualidad)
- Botones WhatsApp con mensajes predefinidos (cotización general y viajes recurrentes)
- Botón flotante de WhatsApp (FAB) con animación de entrada
- Descarga de contacto VCF con instrucciones iOS/Android
- Sección de viajes recurrentes programables
- Mapa de cobertura placeholder con horarios (L-D 06:00-23:00)
- Galería de vehículo con tags informativos
- Grid de 4 modalidades de servicio
- Testimonio con calificación de estrellas
- Tour interactivo de presentación con navegación por teclado
- Modo oscuro/claro con persistencia en localStorage

### Mejoras técnicas
- Zero dependencias npm, sin build step
- Scroll reveal con IntersectionObserver nativo
- Efecto ripple en botones
- Micro-interacciones en hover (cards, iconos)
- Diseño mobile-first responsivo hasta 640px+
- CSS variables para theming adaptativo

### Bugs conocidos
- Ninguno conocido en versión demo
